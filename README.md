# Sistema de Irrigação de plantas domésticas IoT
Projeto de um sistema embarcado para irrigação doméstica usando ESP32 Devkit

## Firmware Tecnologies

- **IDE**: VS Code
- **Board**: ESP32 Devkit 
- **Languages**: C/C++
- **Framework**: Arduino
- **Communication**: UART.
- **Protocols**: Wi-Fi e MQTT

## Firmware Setup

Instalação do ambiente de desenvolvimento e inclusão de bibliotecas
